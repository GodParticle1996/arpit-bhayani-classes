# ADR-0004: Redis client template mein, par optional

**Status:** accepted (template 1.2.0)

## Decision
Redis client pre-integrated (pool, timeouts, metrics). Jo service cache use nahi karti, manifest mein reason ke saath opt-out kare.

## Kyun
Jo teams cache chahti hain unka setup 0 din; jo nahi chahti unpar zabardasti nahi — reason likha ho toh.
